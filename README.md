# AI Awareness for Students

A project to help students understand what Artificial Intelligence is, how it works, where it is used, and how to use it responsibly.

## Overview

This repository contains learning material, examples, and resources for building AI awareness among students. It is meant to be beginner-friendly and requires no prior programming or maths background.

## Objectives

- Explain core AI, Machine Learning, and Deep Learning concepts in simple terms
- Show real-world applications of AI (healthcare, agriculture, transport, education)
- Encourage responsible and ethical use of AI tools
- Build awareness of AI risks: bias, misinformation, privacy, and over-reliance
- Introduce hands-on demos and activities

## Getting Started

### Prerequisites

- Python 3.9 or later (if running the demos)
- Git

### Setup

```bash
# Clone the repository
git clone <your-repo-url>
cd AI_Awarness_Students

# Create and activate a virtual environment
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS / Linux

# Install dependencies
pip install -r requirements.txt
```

## Topics Covered

1. What is AI? A brief history
2. Machine Learning vs Deep Learning
3. How AI models learn from data
4. Everyday AI applications
5. Generative AI and large language models
6. Ethics, bias, and privacy
7. Using AI tools responsibly for studying
8. Careers and future skills in AI

## Usage

- Browse `docs/` for reading material and handouts
- Open `presentations/` for session slides
- Run notebooks in `notebooks/` using Jupyter:

```bash
jupyter notebook
```
